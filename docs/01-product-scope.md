# Product Scope

## Core Goal

Remove highly distracting reels discovery surfaces while keeping core social utility:

- Stories
- Feed posts from followed accounts
- Direct messages
- Ability to open a reel directly when a friend sends it

## Required Behavior

- No reels tab.
- Home should only show posts from followed accounts.
- Search should only show posts from followed accounts.
- If a reel is opened from a direct share, endless scroll into more reels is disabled.
- Visual quality should be high and interactions should feel smooth.

## Hard Constraints Chosen

- Platform: iOS only
- Device type: standard non-jailbroken iPhones
- Must modify the official Instagram app directly
