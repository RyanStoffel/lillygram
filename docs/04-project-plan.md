# Project Plan

## Planning Outcome

Primary request remains:

- iOS only
- Non-jailbroken
- Direct modification of official Instagram app

This is expected to be blocked, so the plan uses a two-track strategy:

1. Attempt an official-app feasibility spike.
2. Pivot to a separate reels-free iOS app if the spike confirms impossibility.

## Workstreams

1. Feasibility spike for official-app modification path.
2. Pivot-ready architecture for standalone app path.
3. UX specification to preserve stories/posts/messages behavior targets.
4. Build plan and quality gates.

## Draft Deliverables Once Direction Is Unblocked

- Functional specification for each feed surface.
- Navigation and interaction rules for reels suppression.
- Visual design system and motion standards.
- Engineering architecture and module boundaries.
- Test strategy for smoothness and behavior guarantees.
