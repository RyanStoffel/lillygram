# Better Instagram Planning Docs

This folder contains planning documents for a reels-free Instagram experience.

Because the target was set to **iOS only**, **non-jailbroken devices**, and **modifying the official Instagram app**, this plan is currently blocked by iOS platform restrictions.

The documents here capture:

1. Product goals and constraints.
2. Feasibility findings for iOS.
3. Viable and non-viable technical options.
4. Execution plan and branch workflow.
